# POCUS tutorials

Adapted from the owner-provided “Masterclass Gastric US.html” and “Masterclass US Lines.html”. The teaching text, cases, quizzes, calculators, simulations and source attributions are preserved. Original files remain unchanged.

`gastric/` contains the gastric ultrasound masterclass and its local scan images, posters and videos. `vascular-access/` contains the arterial / intravenous cannulation masterclass and its reference images. Media were extracted from embedded data; no image content was altered. Keep clinical scan colours and source attributions intact.

Shared headers and footers use the site shell. `assets/pocus-course.css` controls the course viewport and responsive layout; `assets/pocus-course.js` adds section selection, synchronised chapter state and accessible tutorial contents. The reading bar exposes Previous, Next and Contents; presentation timers and theme/fullscreen buttons are hidden from the reading interface. The introductory banners and directory use a new decorative ultrasound-equipment illustration in the ETHER aesthetic (`assets/ether-pocus-equipment.webp`). Clinical scans and simulation geometry are unchanged. Keep both tutorial pages’ noindex tags.

The top navigation is shared with the other site pages. `assets/header-nav.css` supplies the responsive header; `assets/navigation.js` handles the mobile menu and dropdowns. Update the common header on all pages when changing navigation.
