AC guide editor

Edit the password-locked Guide to AC Life. Everything happens in this browser tab. The unlocked guide is never uploaded or saved unless you download it.

  1. Load the current guide and unlock it with the password.
  2. Edit the text. Use Preview to check how it looks.
  3. Lock and download the new index.html.
  4. On GitHub, open the ac folder, choose Add file → Upload files, and upload it. It goes live in about a minute.
