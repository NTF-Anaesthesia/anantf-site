# Fonts for the OT simulator monitor

Self-hosted (no request to Google when the page loads), copied from `bis-dsa/fonts/`. Latin subset, variable weight,
from Google Fonts:

- `Arimo-latin-var.woff2`: Arimo (Apache License 2.0), an Arial/Helvetica-metric look-alike, for the monitor's numbers
  and labels.
- `ArchivoNarrow-latin-var.woff2`: Archivo Narrow (SIL Open Font License 1.1), for the narrow lane and box captions.

Licences: <https://github.com/google/fonts/tree/main/apache/arimo> and <https://github.com/google/fonts/tree/main/ofl/archivonarrow>.
